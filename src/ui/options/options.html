本地视频或无痕模式下看不到速度控制？

          

            要为本地媒体（例如「文件 > 打开文件」）或无痕模式启用播放，你需要
            手动为该扩展授予额外权限。
          

          
    
            
  • 在新标签页中访问 chrome://extensions
    • 
            
  • 
              在列表中找到「视频速度控制器」扩展，并启用「允许访问文件网址」和/或「在无痕模式下启用」。
            
    • 
          


          
如何在某个特定站点上禁用该扩展？

          

            前往 高级 > 站点规则，添加一条包含该站点域名 （例如
            example.com）的规则，并勾选 禁用 复选框。该
            扩展将不会在该站点注入。你也可以使用类似
            /\.edu$/i 的正则模式来匹配多个域名。
          


          
如何为某个特定站点设置默认速度？

          

            在 高级 > 站点规则 中，添加一条包含该站点域名的规则，并把
            速度 字段设置为想要的值（例如 2 表示 2 倍速）。
            不要勾选「禁用」复选框。该站点上的每个新视频都会以该速度开始播放。
          


          
「记住播放速度」与站点规则如何交互？

          

            当 rememberSpeed 处于 关闭 状态（默认）时，每次
            页面加载都从 1 倍速开始 — 如果有匹配的站点规则，则以规则速度开始。你在
            会话中的速度更改会应用于所有新视频，但页面刷新后会被遗忘。
          

          

            当 rememberSpeed 处于 开启 状态时，你最后设置的
            速度会被存储并跨会话保留。这个已存储的速度 优先于
            站点规则默认值。若要让站点规则重新生效，请关闭
            rememberSpeed，或手动重置为 1 倍速。
          


          
某个网站的键盘快捷键和我的冲突了，该怎么办？

          
三种方案：

          
    
            
  • 
              添加修饰键：在 设置 > 快捷键 中，为你的快捷键添加
              Shift、Ctrl 或 Alt，创建网站不会 拦截的组合键。
            
    • 
            
  • 重新绑定到未使用的按键：把默认按键改为该网站未使用的按键。
    • 
            
  • 
              启用独占模式：在 首选项 中打开
              独占键盘快捷键，以阻止网站同时处理你的 VSC 快捷键。
            
    • 
          


          
控制器与网站自身的控件重叠了，如何重新定位？

          

            前往 高级 > 自定义 CSS。使用 --vsc-domain CSS
            变量添加一条针对 vsc-controller 的域名规则。例如：
          

          

            :root[style*='--vsc-domain: "example.com"'] vsc-controller { position: relative; top:
              60px; }
          

          
你也可以在任意页面上把控制器拖动到新位置。可以参考现有的 YouTube、Netflix 等规则。


          
控制器在某个站点上不出现，为什么？

          
常见原因：

          
    
            
  • 
              该站点在你的 站点规则 中且勾选了「禁用」—
              请移除该规则或取消勾选。
            
    • 
            
  • 
              该站点使用 Flash 或非 HTML5 播放器 — 该扩展只适用于原生
              <video> 和 <audio> 元素。
            
    • 
            
  • 
              已启用 默认隐藏控制器 — 按下你的显示切换
              快捷键（默认：V）即可显示它。
            
    • 
          


          
在 YouTube 等单页应用上跳转页面时速度会重置？

          

            YouTube 使用 SPA 导航 — 页面不会完全重新加载，但播放器可能会
            重新初始化。扩展会自动从会话内的值恢复速度。如果速度仍然重置，请在 首选项中启用
            rememberSpeed，以跨导航和会话保留速度。
          


          
它只对视频有效，还是也支持音频元素？

          

            都支持。当在 首选项中启用 音频支持（默认开启）时， 控制器也会出现在
            <audio> 元素上。所有速度控制和 键盘快捷键对音频同样适用。
